# archive — 根目录归档

根目录只保留运行/发布必需文件；历史杂项放这里，不影响日常使用。

| 路径 | 说明 |
|------|------|
| `WORKSPACE.md` | AI/会话操作长日志（历史） |
| `session/` | 旧会话提示词草稿 |
| `dev-tools/` | 一次性验收脚本等 |
| `mockups/` | UI 预览稿、测试截图 |
| `local-notes/` | 本地备注；**可能含敏感信息，勿对外分享** |
| `browser-extension.zip` | 扩展打包副本（源码在 `/browser-extension`） |

运行项目请看根目录 `README.md` / `start.py` / `打包_gui_launcher.bat`。
